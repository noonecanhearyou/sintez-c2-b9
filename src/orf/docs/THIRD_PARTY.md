# Зависимости

- Qt 6: Qt Core, Widgets, Concurrent; используются динамические библиотеки.
  В локальном комплекте Qt 6.10.2 из пакетов Ubuntu. Лицензии Qt и остальных
  библиотек находятся в `runtime/licenses/`; сведения о пакетах сохраняются там.
  Полные тексты лицензий, применимые к конкретному компоненту, указаны в его copyright.
- nlohmann/json 3.11.3: заголовки в `third_party/nlohmann/`, MIT;
  copyright — `third_party/nlohmann/COPYRIGHT`.
- Biopython 1.88: используется исходным Python-стендом и сравнительными тестами.
  Не требуется приложению, не встраивается в исполняемый файл.

C++-алгоритмы перенесены с предоставленного Python-стенда. Порядок выбора
равнооптимального пути проверен по реализации Gotoh установленного Biopython.
Исходники C-расширения Biopython в приложение не копировались.

`runtime/` — локальный комплект для запуска на текущей системе; системные libc,
libstdc++ и графические драйверы в него не включены. Перед распространением
бинарного комплекта учитывайте требования лицензий всех включённых компонентов.
