# LibreGenesis — сборка из исходников

## Требования

C++17, CMake >= 3.21, Qt >= 6.2 с компонентами Core, Gui, Widgets, Concurrent и Test. Для компиляции приложения BLAST+ и HAL не нужны; для выполнения нового анализа нужны нативные blastp, tblastn, makeblastdb, halStats, halLiftover, hal2fasta, а для загрузки баз — curl и gzip. Добавьте каталоги инструментов в PATH до запуска приложения. Бинарники этих инструментов, биологические базы и пользовательские входные данные в исходники не включены.

## Сборка из корня репозитория

```sh
cmake -S src -B build-src -DCMAKE_BUILD_TYPE=Release
cmake --build build-src --parallel 4
ctest --test-dir build-src --output-on-failure
```

Или из этой папки:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 4
ctest --test-dir build --output-on-failure
```

Если Qt установлен нестандартно, добавьте к первой команде `-DCMAKE_PREFIX_PATH=/путь/к/Qt`.

## Запуск

При сборке из корня репозитория:

- Linux: `./build-src/LibreGenesis`
- macOS: `open build-src/LibreGenesis.app`

При сборке внутри src замените build-src на build. Сборка запускается с установленным Qt; создание переносимого пакета со всеми библиотеками является отдельным этапом. В интерфейсе выберите собственные HAL, TXT и CSV: демонстрационные файлы исходного проекта здесь отсутствуют.

## Структура

- app/ — GUI, оркестратор, классификатор, ресурсы и тесты.
- homology/ — поиск гомологов и конфигурации биологических источников.
- synteny/ — анализ синтении через HAL.
- orf/ — анализ ORF; third_party содержит nlohmann/json и его уведомление об авторских правах.

Точка сборки — только этот корневой CMakeLists.txt. Отдельные устаревшие интерфейсы модулей не используются. Тест с реальным HAL/TXT/CSV без этих входных файлов штатно пропускается; остальные проверки выполняются без биологических баз. Linux-сборку следует проверить на Linux: проверка этого комплекта отправителем выполняется на macOS.

Для референса D. melanogaster включена предварительная проверка происхождения по ветвям. Итоговые метки статьи не используются при классификации. Кандидаты с локальной поддержкой отображаются как «De novo (кандидат)». Внешние фильтры UniProtKB и NCBI не входят в этот этап.
