# Расширенный анализ и исключение Aedes aegypti

Итог текущей работы: 27 видов без Aedes aegypti, 780 генов, 53 целевые базы и 41 340 состояний query/target. Авторитетный завершённый набор результатов — `results/without_aaeg/`. Выводы находятся в `results/without_aaeg/REPORT.md`.

Все биологические данные 28 видов исходного CSV скачаны и проверены. Aedes aegypti исключён из итогового анализа по решению пользователя: его завершённый белковый поиск не используется, а геномные попытки остановлены. Это явно сохранено в excluded_species конфигурации и манифеста; исключение не является отрицательным результатом поиска.

## Повторный запуск без Aedes aegypti

Из корня проекта, после сборки:

```sh
homology/build/homology-cli prepare homology/examples/sources.without-aaeg.json homology/data
homology/build/homology-cli run-batch homology/examples/run.without-aaeg.json
```

Перед повторным анализом задайте новый output_dir в копии конфигурации: существующие результаты защищены от перезаписи.

Проверка готовой сводки:

```sh
homology/build/homology-audit homology/examples/sources.without-aaeg.json homology/data homology/results/without_aaeg
```

Файлы sources.all.json и run.all.json сохраняют полный набор 28 видов для возможного будущего анализа. Завершённого анализа всех 28 видов в этой работе нет.

## Пакетное выполнение и воспроизводимость

parallel_targets задаёт число одновременно обрабатываемых баз, threads — число потоков каждого BLAST-процесса. Qt-адаптер HomologyJob выбирает runBatch, если parallel_targets больше 1.

Каждая база имеет собственный дочерний каталог с таблицами, raw-выводом, индексом и run.json. batch_status.json отражает ход выполнения; finished означает завершение вызова, а результат нужно проверять по run_status или дочернему run.json. Общие таблицы формируются после объединения.

Текущий анализ выполнялся по группам с одновременной загрузкой данных. Финальный run.json ссылается на успешные результаты первых двух групп и на 26 отдельных результатов третьей группы. Неуспешные и исключённые попытки Aedes aegypti в него не включены. План объединения сохранён в results/merge_plan.without-aaeg.json. Для обычного нового запуска достаточно одной команды run-batch выше.

resume_batch=true позволяет повторно использовать совместимые завершённые дочерние поиски прерванного пакета до формирования общей сводки. Проверяются конфигурация и хэши запросов, целевого FASTA и таблиц соответствия. Каталоги незавершённых/ошибочных поисков автоматически не удаляются; для полного повторения используйте новый output_dir.

source_ready_file и wait_for_sources_seconds позволяют дождаться метаданных полностью подготовленной базы. Частично скачанный FASTA не считается готовностью.

## Режим многопоточности

Опциональное поле mt_mode: 0 — автоматический выбор BLAST, 1 — распределение запросов, 2 — распределение базы. По умолчанию используется выбор BLAST. Ручной ThreadByQuery проверялся для крупного генома Aedes aegypti, но поиск остановлен по решению пользователя и его результаты не интерпретируются. [Документация NCBI](https://www.ncbi.nlm.nih.gov/sites/books/NBK571452/).

## Ошибки источников

prepare записывает preparation_status.json и продолжает проверку остальных источников при ошибке одного вида. Если в опубликованном списке NCBI нет протеома/GFF, но есть геном, источник может быть подготовлен как genome_only. Недостающая аннотация не подменяется другой сборкой. Соответствующую белковую цель нужно явно отключить с enabled=false и disabled_reason; итог должен сохранять not_run, а не отсутствие гомологов.
